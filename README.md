# ebt-1

A simple static web project containing an HTML page and CSS styles.

## Files

- `index.html` — main HTML file for the application.
- `style.css` — stylesheet for page layout and design.

## Usage

1. Open `index.html` in a web browser.
2. Edit `style.css` to customize the appearance.

## Notes

- No build step is required.
- This repository is intended for static web development and quick prototyping.
